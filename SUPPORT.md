# Support

- Usage questions and reproducible bug reports: open a GitHub issue.
- Security-sensitive reports: follow `SECURITY.md` and do not post details in a
  public issue.
- Research-result questions: cite the exact experiment directory, seed, input
  data, and output record.

PRISM is maintained on a best-effort basis. Maintainers aim to acknowledge
ordinary issues within two weeks. No response-time guarantee is provided.
