# References Directory

Use this directory for papers, source notes, citation metadata, and literature
review artifacts.

Recommended layout:

```text
references/
  papers/
  notes/
  bib/
```

For each paper or external source, record:

- Citation.
- Link or source path.
- Date accessed or reviewed.
- Research question it informs.
- Key claims and methods.
- Limitations.
- How it affects PRISM decisions or open questions.

Record source-review summaries in `docs/LITERATURE_LOG.md`.
