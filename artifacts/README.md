# Artifacts Directory

Use this directory for generated research outputs that are not primary source
documents.

Recommended subdirectories:

- `figures/` for exported plots and diagrams.
- `tables/` for result tables and summaries.
- `logs/` for command output and execution logs.
- `models/` for saved model or network artifacts.
- `exports/` for rendered PDFs, slides, or derived reports.

For each meaningful artifact, record:

- Purpose.
- Producing script, notebook, or command.
- Input data and configuration.
- Date generated.
- Related iteration note.
- Whether it supersedes an older artifact.

Update `docs/ARTIFACT_INDEX.md` when adding important artifacts.
