# Scripts Directory

Use this directory for reusable automation and reproducibility scripts.

Recommended categories:

- Experiment runners.
- Notebook execution wrappers.
- Result aggregation scripts.
- Plot/export scripts.
- PDF or slide build scripts.
- Environment capture scripts.

Each script should include or be accompanied by:

- Purpose.
- Required inputs.
- Expected outputs.
- Example command.
- Dependencies.
- Related iteration or experiment.

Avoid putting one-off exploratory code here unless it becomes reusable.
